Is this demo actually using AI?

No. It uses deterministic scripts for summaries, checklists, a sample email rewrite and a code explanation. Unknown prompts get an honest fallback. Nothing connects to an LLM.

Can it access my files or apps?

Not this website. The three windows are editable examples inside the page. Apply changes only to that example. The native app separately requires signing, OS permissions and deliberate configuration.

What stays private in the demo?

Prompt and document text stay in this tab’s memory, not storage or the URL. No analytics, third-party assets or inference endpoints. GitHub hosts the static site. Copy writes only after you explicitly click Copy.

How does the native app handle safety?

Native actions validate the original target, focus, ownership, geometry and live permissions. Credential input defaults off. Deletion checks are defense in depth, not a filesystem sandbox; trusted extensions are arbitrary code. Full accessibility, live-model and distribution acceptance are still pending.
